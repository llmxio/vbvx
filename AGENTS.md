# Repository Guidance

VBVX keeps detailed harness instructions in focused files under `docs/`.
Read the relevant file before changing the matching part of the project:

- `docs/harness-project.md` for repository layout and module ownership.
- `docs/harness-commands.md` for build, test, and documentation commands.
- `docs/harness-coding-rules.md` for C++ style, packet layout, and tests.
- `docs/harness-contribution.md` for commit, pull request, and agent rules.

Keep this root file as an index. Update the harness file that owns a rule
instead of expanding `AGENTS.md`.
